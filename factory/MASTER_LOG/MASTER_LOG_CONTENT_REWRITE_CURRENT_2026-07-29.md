## 0. 이 문서의 목적

이 문서는 새 글 한 편을 쓰기 위한 문서가 아니다.

Savingio 애드센스 재승인을 위해 진행 중인 **전체 177개 운영 URL의 검색 의도 분석, 대표글 선정, 중복 통합, 301 리디렉션, 내부링크 정리, 목록 정리, 고품질 재작성** 작업을 다음 대화에서도 잊지 않고 그대로 이어가기 위한 현재 인수인계 문서다.

GitHub `main`이 최종 기준이며, 매 턴 시작 시 먼저 실제 저장소와 최신 커밋을 확인한다. 확인 없이 `없다`, `읽을 수 없다`, `쓸 수 없다`고 답하지 않는다.

## 1. 최종 목표

1. 애드센스 재승인
2. 가치가 낮거나 검색 의도가 겹치는 글 축소
3. 대표글 중심의 문제 해결 구조 완성
4. 모든 대표글을 Savingio V2 글쓰기 헌법 기준으로 재작성
5. 통합 URL은 301 처리
6. 삭제·통합 후 내부링크, 목록, 검색 데이터, 사이트맵까지 정리
7. GitHub 반영과 실제 배포 확인 전에는 PASS 금지

현재 작업은 검색트리·메인 UI 개발이 아니라 **콘텐츠 품질과 중복 축소가 우선**이다. 검색트리 문제는 콘텐츠 작업 완료 후 별도 일괄 정비한다.

## 2. 변경된 작업 방식

| 기존 방식 | 확정 방식 |
|---|---|
| 계획·보고서 작성 중심 | 실제 파일 수정 우선 |
| 목록만 분류 | 대표글 통합·중복 URL 실제 정리 |
| 장시간 설명 | 완료 결과표만 보고 |
| 글 수 유지 | 검색 의도 중복 글 실제 축소 |
| 추정 PASS | GitHub 반영·배포 확인 후 PASS |

실행 순서:

`통합 1건 완료 → 301 → 내부링크 → 글 목록/검색 데이터 정리 → 검증 → 결과표`

177개를 한 번에 메모리에 올리지 않는다. GitHub를 데이터베이스처럼 사용하여 20~30개 단위로 읽고, 분석 결과를 MASTER CONTENT MAP V2와 클러스터 결정 문서에 누적한다.

## 3. Savingio V2 글쓰기·통합 LOCK

- 기존 글 재작성 시 URL, 파일명, H1, slug, 카테고리만 보존한다.
- 기존 본문은 재사용하지 않고 처음부터 새로 작성한다.
- 기준 DNA는 `articles/car-aircon-fuel-saving.html`이다.
- 데스크톱 3분할, 왼쪽 Explorer, 중앙 본문, 오른쪽 5개 카드 구조는 임의 변경 금지다.
- 오른쪽 카드는 정확히 다음 5개 목적과 순서를 유지한다.
  1. 지금 해야 할 행동
  2. 계산기/점검도구
  3. 같은 카테고리 글
  4. 함께 볼 관련 글
  5. 다음 단계/주의사항
- 본문 흐름:
  `Lead → 작성·검수 → 5초 결론 → 30초 질문 → 지금 해야 할 행동 → 목차 → 상세 본문 → 비교표 → 체크리스트/내 상황 찾기 → 사례 → 보험·제도·법률 → 계산기/공식기관 → FAQ → 문제 해결 사슬형 관련 글 → Footer`
- 본문 최소 5,000자 이상. 반복으로 분량을 채우지 않는다.
- 보험·법률·정책·수치는 최신 공식 기준을 확인하고 단정하지 않는다.
- 중복 URL·파일명·H1·검색 의도·본문·계산기·관련 링크를 사전 확인한다.
- 한 번에 한 글 또는 한 통합 건씩 실제 처리한다.
