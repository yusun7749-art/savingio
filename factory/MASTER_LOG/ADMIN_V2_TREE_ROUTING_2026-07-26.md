# Savingio Admin V2 좌측 검색트리 연결 복구 기록

최종 갱신: 2026-07-26 KST
저장소: `yusun7749-art/savingio`
브랜치: `main`

## 사용자 명령

- 메인 화면에 흩어진 기능을 페이지별 좌측 검색트리 안으로 정리한다.
- 콘텐츠본부, 쇼츠·영상본부, SNS 배포본부, 상품·수익본부 등 이름만 있는 트리에는 이름에 맞는 하위 업무 구조를 만든다.
- 기존 기본 틀은 유지하고 각 트리 항목 클릭 시 중앙 작업영역에 해당 페이지가 표시되도록 연결한다.
- 새 Router, 새 Workspace, 중복 트리, 별도 카드 화면을 임의로 추가하지 않는다.

## 반복 실패 증상

- 좌측 트리의 본부명 또는 하위 항목을 클릭해도 중앙 페이지가 교체되지 않았다.
- 제목만 바뀌거나 아무 변화가 없었다.
- 새 내용이 기존 화면의 가장 아래 `departmentBoard`에 렌더링되어 하단에서 찌그러져 보였다.
- 페이지별 전용 화면 연결 없이 이름과 표만 추가된 상태를 연결 완료로 잘못 보고했다.

## 확인된 실제 원인

1. `admin/admin.js`가 `#treeNav` 클릭을 처리했다.
2. `admin/os/module-workspace.js`도 같은 `#treeNav` 클릭을 처리했다.
3. `admin/department-pipeline.js`도 다시 같은 `#treeNav` 클릭을 처리했다.
4. 여러 핸들러가 같은 클릭을 서로 다른 방식으로 처리해 중앙 화면 상태를 다시 덮어썼다.
5. 부서 작업 영역 `.department-panel` 자체가 메인 HTML의 모든 홈/콘텐츠 섹션 아래에 위치해 있어, 라우팅이 되더라도 화면 하단에 나타났다.
6. `hidden` 속성만 사용한 기존 방식은 다른 스타일·렌더러와 충돌할 여지가 있었다.

## 폐기한 접근

- 클릭이 안 될 때 새 라우터를 또 추가하는 방식
- 기존 하단 작업판에 표만 덮어쓰는 방식
- 실제 화면 확인 없이 `파이프라인 연결됨` 문구만 표시하는 방식
- 여러 스크립트가 동시에 트리를 처리하도록 두는 방식
- 제목 변경을 페이지 연결로 간주하는 방식

## 이번 실제 수정

### 1. 중복 모듈 자동 로딩 제거

- `admin/admin-data.js`에서 `module-registry.js`, `module-engine.js`, `module-workspace.js`, `module-manager.js` 자동 로딩을 제거했다.
- 좌측 트리를 추가로 가로채던 Module Workspace 경로를 끊었다.

관련 커밋:
- `d74de0bd797f695e387b086d2511b5acda66c252`

### 2. 단일 중앙 라우팅 엔진으로 재작성

수정 파일:
- `admin/department-pipeline.js`

적용 내용:
- DOM 준비 후에만 라우터가 시작되도록 변경했다.
- `.department-panel`과 콘텐츠센터를 실행 시 상단 Topbar 바로 아래로 이동한다.
- 하단 렌더링 위치를 중앙 작업영역으로 강제했다.
- 홈, 통합 상황실, 콘텐츠센터, 부서 작업판을 한 번에 하나만 표시하도록 정리했다.
- `hidden`과 `display:none !important`를 함께 사용해 이전 화면이 남지 않도록 했다.
- 좌측 검색트리 클릭은 Capture 단계의 단일 권한 핸들러가 처리한다.
- `preventDefault`, `stopPropagation`, `stopImmediatePropagation`으로 기존 하위 클릭 핸들러의 재처리를 차단한다.
- 본부 루트 클릭 시 해당 본부 하위 업무 구조를 중앙에 표시한다.
- 하위 업무 클릭 시 해당 업무 페이지를 중앙에 표시한다.
- URL에 `dept`, `task`를 기록하고 뒤로가기 동작을 연결한다.

관련 커밋:
- `136b42e0f699cfcaa930a20da724d4848c751157`

## 완료 판정 조건

아래를 실제 운영 화면에서 모두 확인하기 전에는 PASS로 기록하지 않는다.

1. 통합 상황실 클릭 시 기존 메인 상황실만 보인다.
2. 통합 상황실 하위 항목 클릭 시 중앙 영역이 해당 페이지로 교체된다.
3. 시장분석본부 클릭 시 중앙 상단에 하위 업무 구조가 표시된다.
4. 콘텐츠본부, 쇼츠·영상본부, SNS 배포본부, 상품·수익본부도 같은 방식으로 표시된다.
5. 하위 항목 클릭 시 페이지가 하단에 추가되지 않는다.
6. 이전 페이지가 함께 남지 않는다.
7. 좌측 트리 너비나 전체 레이아웃이 쪼그라들지 않는다.
8. 브라우저 새로고침과 뒤로가기 후에도 선택 페이지가 유지된다.
