# SAVINGIO 공식 글쓰기 헌법 V2
## Ultimate Content Constitution

이 문서는 Savingio 전체 콘텐츠 품질 개선, 통합, 삭제, 301 Redirect, 대표글 재작성의 최상위 기준이다.

## 제1조. 목적
Savingio의 목표는 글을 많이 만드는 것이 아니라 대한민국에서 가장 좋은 정보를 제공하는 사이트를 만드는 것이다.

## 제2조. 대표글 원칙
대표글은 단순한 대표 페이지가 아니라 그 주제의 최종 가이드다. 사용자가 검색해서 들어온 순간 다시 검색하지 않아도 될 정도로 궁금증을 해결해야 한다.

## 제3조. 검색 의도 우선
제목으로 글을 만들지 않는다. 검색 의도를 먼저 분석한다. 같은 검색 의도라면 모두 하나의 대표글로 통합한다.

## 제4조. 기존 글 처리
기존 글의 문장은 재사용하지 않는다. 정보, 사례, 표, 공식자료, 질문만 참고한다. 본문은 항상 처음부터 다시 작성한다.

## 제5조. 통합 원칙
대표글 작성 전에 관련 글 전체를 조사한다.
- Savingio 기존 글
- 정부자료
- 공식기관
- 실제 사례
- 자주 묻는 질문
- 변경사항
- 누락된 내용

## 제6조. 질문 중심 작성
목차부터 만들지 않는다. 먼저 사용자가 궁금해할 질문을 최대한 많이 만든 뒤, 그 질문을 모두 해결하는 방식으로 작성한다.

## 제7조. 정보 완결성
글자수는 기준이 아니다. 5,000자, 10,000자, 15,000자, 20,000자 모두 가능하다. 기준은 더 이상 궁금한 것이 남지 않는가이다.

## 제8조. 완료 기준
완료란 글을 다 쓴 상태가 아니라 다음 질문이 남아 있지 않은 상태다.

필수 완료 요소:
- 검색 의도 해결
- FAQ 해결
- 공식기관 확인
- 계산기
- 비교표
- 체크리스트
- 사례
- 예외사항
- 실수
- 다음 행동

## 제9조. 중복 콘텐츠
같은 검색 의도는 절대 여러 글로 운영하지 않는다.

대표글 → 관련글 흡수 → 기존 글 삭제 → 301 Redirect → 대표글 유지

## 제10조. Savingio 품질 기준
Savingio는 애드센스를 위해 글을 쓰지 않는다. SEO를 위해 글을 쓰지 않는다. 사용자가 “이 글 하나면 끝이다”라고 느끼는 콘텐츠를 만든다. 그 결과로 애드센스, SEO, 체류시간, 북마크, 재방문이 따라온다.

## 제11조. 최우선 원칙
한 페이지에서 해결할 수 있는 내용은 절대 여러 페이지로 나누지 않는다. 다만 검색 의도가 명확히 달라지는 경우에만 새로운 대표글을 만든다.

- 같은 검색 의도 → 하나의 초고품질 대표글
- 다른 검색 의도 → 별도의 대표글

## 전체 작업 순서
1. 관련 글 전체 분석
2. 검색 의도 군집화
3. 대표글 결정
4. 대표글 본문 완전 재작성
5. 관련 정보 흡수
6. 중복·저가치 글 삭제
7. 301 Redirect 설정
8. 내부 링크·사이트맵 정리
9. 실제 페이지 검증
10. 품질 개선 현황판 갱신

## 절대 LOCK
- 기존 글 문장 재사용 금지
- 같은 검색 의도 다중 운영 금지
- 분량만 늘리는 작성 금지
- 공식 확인 없는 수치·제도 단정 금지
- 통합 전 관련 글 조사 생략 금지
- 삭제 후 301 Redirect 누락 금지
- 실제 GitHub 반영 전 완료 처리 금지
- 이 헌법과 충돌하는 임의 작업 금지
