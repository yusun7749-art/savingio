## 1. 전략 변경의 직접 원인

Savingio는 애드센스 재승인이 최우선 목표다.

최근 애드센스 심사에서 사이트에 대해 `가치가 별로 없는 콘텐츠` 판정이 확인됐다.

따라서 현재 문제를 단순히 다음과 같이 해석하지 않는다.

- 글 수가 부족하다.
- 더 많은 글이 필요하다.
- 기존 글에 섹션을 조금 더 붙이면 된다.
- 177개를 모두 살려야 한다.

실제 핵심 문제는 다음일 가능성이 높다.

- 검색 의도가 겹치는 다수의 글
- 서로 비슷한 내용을 나눈 얇은 콘텐츠
- 사이트 내부에서 같은 키워드를 두고 경쟁하는 구조
- 사용자가 한 글만 읽고 문제를 해결하기 어려운 구조
- 글 개수는 많지만 대표 콘텐츠의 힘이 약한 구조

따라서 애드센스 재승인을 위해서는 글을 더 늘리는 것이 아니라, 중복과 분산을 제거하고 분야별 대표 콘텐츠의 밀도를 높여야 한다.

## 3. 폐기하는 기존 전략

아래 방향은 공식적으로 폐기한다.

### 3.1 글 수 유지 목표 폐기

- 177개를 모두 유지한다.
- 현재 URL 수를 성과 지표로 사용한다.
- 삭제나 통합을 실패로 본다.

위 사고방식은 폐기한다.

### 3.2 글 수 확대 목표 폐기

- 200개 이상을 채운다.
- 카테고리마다 글 수를 맞춘다.
- 빈 키워드를 발견하면 우선 새 글부터 만든다.

위 사고방식은 애드센스 재승인 전에는 사용하지 않는다.

### 3.3 기존 DNA 일괄 교체 방식 폐기

예전에 승인했던 DNA 구조를 177개 글에 그대로 반복 적용하는 방식은 더 이상 최종 기준이 아니다.

기존 DNA는 과거 시점의 품질 기준이며, 현재 애드센스 재승인을 위한 최고 품질 기준으로 다시 설계해야 한다.

따라서 다음 표현을 사용하지 않는다.

- 기존 DNA로 한 글씩 교체
- A001 스타일로 전체 변환
- 기준 글을 복제해서 제목과 내용만 교체

### 3.4 기존 글 덧씌우기 방식 폐기

- 기존 문단을 최대한 남기고 섹션만 추가
- 짧은 내용을 반복해 글자 수만 확대
- 기존 HTML의 빈 칸을 채우는 방식

위 접근을 폐기한다.

대표글은 기존 내용을 복사하거나 이어 붙이는 방식이 아니라, 검색 의도와 문제 해결 흐름을 먼저 새로 설계한 후 처음부터 작성한다.

## 4. 새 콘텐츠 운영 헌법

### 핵심 원칙

**한 검색 의도 = 한 개의 초고품질 대표 페이지(Ultimate Page)**

사용자가 같은 목적을 가지고 검색할 수 있는 여러 키워드가 존재하더라도, 실제 해결해야 할 문제가 하나라면 글도 하나로 통합한다.

예시:

- 자동차보험 절약
- 자동차보험 할인
- 자동차보험 싸게 가입
- 자동차보험 특약 절약
- 자동차보험료 줄이는 방법

위 검색이 본질적으로 같은 문제를 해결한다면 별도 글 여러 개를 유지하지 않는다.

`자동차보험을 가장 저렴하게 가입하고 갱신하는 방법`이라는 대표글 하나로 통합하고, 그 글 안에서 필요한 하위 문제를 모두 해결한다.

## 5. Ultimate Page의 품질 기준

대표글은 단순히 긴 글이 아니다.

사용자가 검색 후 다른 사이트나 다른 Savingio 글을 다시 찾아다니지 않아도 될 만큼 문제를 끝까지 해결해야 한다.

대표글에는 주제에 맞게 다음 요소를 포함한다.

1. 사용자가 실제로 이 검색을 한 상황
2. 지금 당장 해야 할 행동
3. 5초 안에 이해할 핵심 결론
4. 내 상황을 구분하는 질문과 조건 분기
5. 실수하기 쉬운 지점
6. 단계별 실행 방법
7. 조건별 비교표
8. 준비물 또는 확인 서류 체크리스트
9. 실제 사례와 실패 사례
10. 비용, 환급, 할인, 기간 등 필요한 수치 설명
11. 보험·세금·법률·제도상 예외와 주의사항
12. 필요한 계산기 또는 점검 도구
13. 공식기관 연결
14. 자주 묻는 질문
15. 문제 해결 사슬을 이어주는 관련 대표글

글자 수는 목표가 아니다.

필요한 내용을 반복 없이 모두 해결한 결과가 7,000자일 수도 있고 10,000자 이상일 수도 있다. 반대로 불필요하게 분량만 늘리지 않는다.

## 6. 글 수 감소에 대한 공식 판정

최종 글 수가 177개보다 줄어드는 것은 `가능성`이 아니라 `정상 결과`다.

중복 검색 의도를 제대로 제거하면 글 수는 줄어들어야 한다.

따라서 다음을 LOCK한다.

- 글 수 감소를 실패로 보고하지 않는다.
- 삭제 개수보다 살아남은 대표글의 완성도를 본다.
- 통합 가능한 글을 억지로 독립 URL로 유지하지 않는다.
- 카테고리의 빈 숫자를 채우기 위해 얇은 글을 만들지 않는다.
- 최종 글 수를 미리 정하지 않는다.
- 검색 의도 분석 결과에 따라 필요한 대표글만 남긴다.

성과 지표는 `몇 개 남았는가`가 아니라 다음이다.

- 중복 검색 의도가 제거됐는가?
- 각 대표글이 사용자 문제를 끝까지 해결하는가?
- 내부 키워드 경쟁이 줄었는가?
- 관련 글 연결이 문제 해결 순서로 이어지는가?
- sitemap과 실제 파일과 검색 데이터가 일치하는가?
- 흡수된 URL이 올바른 대표글로 301 연결되는가?

## 7. 통합·삭제·리디렉션 규칙

각 검색 의도 그룹에서 다음 세 종류를 결정한다.

### A. 대표글

- 검색 의도를 가장 정확하게 대표하는 URL
- 사용자에게 설명하기 쉬운 명확한 제목과 slug
- 기존 외부 유입, 내부 링크, 구조상 가치가 있는 URL 우선 검토
- 현재 최고 품질 기준으로 본문을 처음부터 새로 작성

### B. 흡수글

- 대표글과 본질적으로 같은 검색 의도
- 일부 하위 정보만 따로 떼어 얇게 만든 글
- 대표글 안에서 충분히 해결 가능한 글

처리:

1. 흡수글의 유용한 정보와 질문을 대표글 설계에 반영
2. 기존 본문은 그대로 복사하지 않음
3. 흡수글 URL을 대표글로 301 연결
4. sitemap에서 제거
5. 검색 인덱스 데이터에서 제거
6. 사이트 내부 링크를 대표글 URL로 변경
7. 원본 HTML 제거

### C. 완전 삭제글

- 검색 의도가 불명확함
- 내용이 잘못됐거나 현재 사이트 방향과 맞지 않음
- 대체할 가치 있는 대표글도 없음
- 임시 파일, 테스트 파일, 의미 없는 변형 URL

완전 삭제 시에도 링크 단절과 404 영향을 확인하고, 관련 대표글이 있으면 적절한 301을 사용한다. 모든 삭제 URL을 무조건 홈으로 보내지 않는다.

## 9. 기존 Savingio 글쓰기 헌법과의 관계

기존 헌법에서 다음은 계속 유지한다.

- 사용자 문제를 먼저 해결한다.
- 보험·법률·정책·수치를 꾸며내지 않는다.
- 조건과 예외를 확인한다.
- URL과 레이아웃을 임의 변경하지 않는다.
- 왼쪽 Explorer와 오른쪽 카드 구조를 임의 삭제하지 않는다.
- 실제 배포와 링크 검증 전 PASS를 선언하지 않는다.

그러나 `기존 DNA를 모든 글에 그대로 적용한다`는 해석은 폐기한다.

기존 DNA는 최소 구조 참고선일 뿐이며, 대표글은 그보다 더 높은 현재의 Ultimate Page 기준으로 설계한다.

특히 기존 177개 URL을 모두 한 글씩 유지하며 재작성하는 것은 현재 전략과 충돌한다.

먼저 검색 의도를 통합하고, 살아남을 대표글만 초고품질로 새 작성한다.
