# 🚨🚨🚨 EMERGENCY ADMIN RED LOCK — 반드시 첫 번째로 읽을 것 🚨🚨🚨

> 이 문서를 읽지 않고 Savingio Admin 관련 작업을 시작하는 것을 금지한다.
> 이 문서와 충돌하는 임의 변경은 실패·회귀로 판정한다.

## 1. 최상위 지위

이 문서는 Savingio Admin의 공식 헌법이며, 관리자 화면·Explorer·리나 Assistant·업무 프로그램·워크플로 관련 모든 설계와 수정에 최우선 적용한다.

Savingio는 일반 웹사이트가 아니라 운영 가능한 OS/HQ다.

## 2. 절대 LOCK

1. `/admin`은 유일한 본사(HQ)다.
2. `/admin/v2.html`과 V2 관련 파일은 실험실이며, 사용자의 명시적 승인 전에는 HQ로 대체하거나 병합하지 않는다.
3. 기존 `/admin` 수정 작업 중 V2 파일을 수정하지 않는다.
4. 왼쪽 Explorer는 단순 메뉴가 아니라 Savingio 조직도이자 모든 프로그램 생성·연결의 기준이다.
5. Explorer를 임의 삭제·축소·재분류·이동하지 않는다.
6. 카드형 대시보드 UI를 새로 만들지 않는다.
7. HQ 기본 레이아웃은 `왼쪽 Explorer / 중앙 업무 프로그램 / 오른쪽 리나 Assistant / 하단 Log` 구조를 유지한다.
8. 리나 Assistant는 운영 비서다. 삭제·비활성화·빈 패널 대체를 금지한다.
9. 기존 프로그램, 경로, 버튼, 런타임, 데이터 연결을 확인하지 않고 새 구조로 교체하지 않는다.
10. 기존 기능을 삭제하거나 이동하기 전에 사용자 명시 승인을 받는다.
11. 예쁘게 보이게 한다는 이유로 업무 구조·탐색 구조·연결을 변경하지 않는다.
12. 실행 가능한 GitHub 작업을 설명으로 대체하지 않는다. 먼저 실제 조회·수정·검증하고, 실패했을 때만 정확한 실패 원인을 보고한다.

## 4. 프로그램 생성 헌법

모든 프로그램은 아래 연결을 따른다.

`Explorer 부서 → 업무 프로그램 → 작업 실행 → QA → 승인 → Git → Cloudflare → 운영 검증`

왼쪽 트리 항목을 만들었으면 중앙 실제 프로그램과 연결해야 한다. 보이는 메뉴만 만들고 실행 프로그램이 없는 상태를 완료로 판정하지 않는다.

## 5. 리나 Assistant 생존 규칙

리나 Assistant는 항상 다음을 제공하는 운영 비서로 유지한다.

- 현재 Explorer 위치
- 현재 열린 프로그램
- 다음 해야 할 일
- 오류·누락 상태
- Git/배포 상태
- 작업 명령 입력
- 실행 로그 연결

정적 문구만 표시하거나 응답하지 않는 상태는 `FAIL — ASSISTANT DOWN`으로 판정한다.

## 6. 변경 우선순위

`기존 구조 유지 → 기존 연결 유지 → 기존 기능 유지 → 오류 복구 → 그 이후 기능 추가`

기존 연결을 깨뜨리는 변경을 발견하면 새 기능 작업을 즉시 중단하고 복구부터 수행한다.
