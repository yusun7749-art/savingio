## 이번 실제 구조 변경

### 1. 기존 Admin 독립 화면 Router

생성 파일:

- `admin/admin-workspace-router.js`

기능:

- 대분류와 모든 소분류를 독립 Route로 등록
- 왼쪽 메뉴 클릭을 capture 단계에서 처리해 기존 제목 변경 전용 이벤트를 차단
- 클릭할 때 기존 메인 섹션을 모두 숨기고 선택한 화면만 표시
- 상단 제목, 왼쪽 활성 메뉴, URL `?view=`를 함께 갱신
- 브라우저 뒤로가기·앞으로가기 지원
- 현재 Route 검증 API 제공

### 2. 메인 화면 축소

`통합 상황실` 메인에는 다음만 남긴다.

- 보안 상태
- 핵심 진행 수치
- 진행 중 프로젝트 요약
- 선택 프로젝트 상세

다음 항목은 메인에서 제거하고 카테고리 화면으로 분리했다.

- 전체 콘텐츠 운영센터
- 전체 부서별 작업판
- 각 운영 부서 상세 업무

### 3. 통합 상황실 하위 화면 분리

- 전체 진행률
- 오늘 작업
- 승인 필요
- 오류·중지
- 수익 요약

각 메뉴가 별도 중앙 화면을 사용한다. 프로젝트 데이터는 카드 묶음이 아니라 표 형태로 표시한다. 실제 수익 데이터가 없으면 금액을 만들지 않고 연결 대기로 표시한다.

### 4. 콘텐츠 운영센터 분리

- 콘텐츠본부 대분류
- 기존 글 재작성
- 콘텐츠 QA

위 Route에서만 전체 글 승인·헌법/DNA 검사 화면을 표시한다. 메인 하단 고정 출력을 중단했다.

### 5. 나머지 본부 화면 분리

다음 본부의 대분류와 소분류 Route를 각각 생성했다.

- 시장분석본부
- 콘텐츠본부
- 쇼츠·영상본부
- SNS 배포본부
- 상품·수익본부
- 승인센터
- 자동화센터
- 데이터·분석본부
- 시스템관리

각 본부는 선택한 업무만 중앙에 표시하며 다른 부서 콘텐츠를 함께 늘어놓지 않는다.
